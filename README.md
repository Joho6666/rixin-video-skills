# 锐新科技 视频 skills

Claude Code skills for making explainer videos for a hardware-education brand (锐新科技):

- `skills/rixin-explainer-video` — 8-segment 方格纸 explainer videos with the brand robot, 9:16 + 16:9.
- `skills/rixin-demo-video` — variant with live demo animations (PWM scope, LED, counter).
- `skills/hybrid-ai-video` — Remotion motion graphics combined with AI images (gpt-image) and AI image-to-video (grok) shots.

Brand mascot sprites, voice/music IDs and client material are NOT included. Place the skills in `~/.claude/skills/` to use them.
