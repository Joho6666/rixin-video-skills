# 和公众号联动：一周 7 天，每天 1 篇文章 + 横竖 2 条视频

文章部分完全按 `wechat-mp-article` skill（风格、选题库、封面、打包都在那里）；本文件只说视频怎么配。

## 选题
- 公众号项目目录里的 `选题库.md` 是唯一待办清单（`# | 栏目 | 标题 | 状态 | 日期`）。取前 7 条「待写」，栏目按「拆解 → 答疑 → 选型局」轮换。
- 霓虹拆解最适合**拆解**栏目（一个完整项目）。答疑 / 选型局的那几天也能用：把「一个项目」换成「一个器件 / 一个问题」，kit 页放器件对比图，layers 写选型维度，chain/ring/pins 讲原理和接法。
- 多补 1 条作为下周第一篇：第 7 天视频的 outro 要预告它。

## 每天的视频
1. 先写文章（或用户已经复刻好的文章），视频从文章取：开场问题 → 实物组成 → 架构 → 闭环 → 三步原理 → 深挖 → 升级 → 下期。
2. topic 名用 `d<编号>_<拼音缩写>`，例如 `d13_wenshi`；beat id 前缀用缩写，避免和别的期撞。
3. outro 的 `next` = **第二天**的文章标题，`items` = 第二天文章的 3 个要点。
4. 按 SKILL.md 的 1–8 步出片。7 期的 `voice` 可以连着跑；`render` 一期一期串行在后台跑（每期横竖约 10 分钟）。

## 交付
每天一个文件夹（和 `make_week_pack.py` 的结构一致）：
```
<序号> <星期> <文章标题>/
  文章.html  文章.md  img/  封面_大.png  封面_小.png
  <标题>_竖版9比16.mp4   ← E:/rx3_out/<topic>/<标题>_锐新科技_9x16.mp4
  <标题>_横版16比9.mp4   ← ..._16x9.mp4
  发布说明.txt           ← 视频标题、话题标签（#单片机 #毕业设计 #STM32 #锐新科技）、图源
```
`一周发布排期.md` 每天一行：公众号标题、视频标题、发布时间、图源是否已标注。

## 发布前检查
- 横竖两条都从头看一遍开头 5 秒和结尾「下期我们讲」是否对上第二天。
- 用了网上图的那几期，画面、文章、发布说明三处的图源一致。
- 数字（电压、倍数、引脚）和文章、素材文件一致。
